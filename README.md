# twse-data：臺灣證券交易所每日盤後資料

本分支只存放證交所 OpenAPI 的官方開放資料，由 `.github/workflows/twse.yml` 每個交易日收盤後自動累積，
供網站的 K 線圖使用。

## 為什麼要自己累積

證交所 OpenAPI 的端點沒有查詢參數，`STOCK_DAY_ALL` 只回傳「最新一個交易日」的全市場行情。
錯過的日子無法再從 OpenAPI 取得，所以本分支**只新增、不覆寫**：一般 commit，從不 force push。

## 資料來源與授權

資料來源：臺灣證券交易所 OpenAPI（政府資料開放平臺「盤後資訊 > 個股日成交資訊」等資料集）。
此開放資料依政府資料開放授權條款（Open Government Data License）進行公眾釋出，
使用者於遵守本條款各項規定之前提下，得利用之。
政府資料開放授權條款：<https://data.gov.tw/license>

每個檔案的 `meta` 也記錄了實際來源網址、取得時間與同一段授權聲明。

## 檔案格式

| 路徑 | 內容 |
| --- | --- |
| `stock_day_all/<年>/<日期>.json` | 上市個股日成交資訊（開高低收、成交股數、成交金額、成交筆數） |
| `mi_index/<年>/<日期>.json` | 每日收盤行情：各類指數收盤值（含發行量加權股價指數） |

每個檔案是 `{"meta": {...}, "rows": [...]}`，`rows` 保留官方原始欄位與字串值（民國日期、`--` 表示當日無成交）。
價格為當日實際成交價，**未還原權值**。

## 不在本分支的資料

模型訓練用的歷史價格取自 Yahoo Finance（yfinance），僅供內部研究、不對外提供，因此不放在任何公開分支。
