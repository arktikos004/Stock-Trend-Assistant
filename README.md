# twse-data：證交所與集保的開放資料

本分支只存放臺灣證券交易所與臺灣集中保管結算所的官方開放資料，由 `.github/workflows/twse.yml`
每個交易日收盤後自動累積（收集程式：`backend/stockta/data/twse.py`），供網站的 K 線圖與研究工作台的篩選條件使用。

## 為什麼要自己累積

這些開放資料沒有查詢參數，只回傳「最新一期」：個股行情、本益比、融資融券是最新一個交易日，
月營收是最新一個月，集保股權分散表是最新一週。錯過的那一期無法再取得，
所以本分支**只新增、不覆寫**：一般 commit，從不 force push。

個股行情、指數、本益比各有兩個官方出口，換日的時間不同：

| 出口 | 網址 | 換成當日資料的時間 |
| --- | --- | --- |
| 政府資料開放平臺登錄的 CSV | `https://www.twse.com.tw/exchangeReport/<資料集>?response=open_data` | 收盤當晚 |
| 證交所 OpenAPI | `https://openapi.twse.com.tw/v1/exchangeReport/<資料集>` | 隔天清晨 |

收集程式每次兩邊都抓，日期不同就各存一份：當晚拿得到今日資料，前一天漏收時還能從 OpenAPI 補回來。

融資融券餘額與外資持股的內容沒有日期，只有平臺 CSV 的下載檔名帶日期（例如 `MI_MARGN_ALL_20261005.csv`），
所以這幾個只抓 CSV、日期取自檔名；判定不了日期的就不收。

| 融資融券與可借券賣出額度 > 融資融券餘額 | [11680](https://data.gov.tw/dataset/11680) | 臺灣證券交易所 | `mi_margn/` |

| 三大法人 > 外資及陸資持股前 20 名彙總表 | [11656](https://data.gov.tw/dataset/11656) | 臺灣證券交易所 | `mi_qfiis_sort_20/` |
| 上市公司每月營業收入彙總表 | [18420](https://data.gov.tw/dataset/18420) | 臺灣證券交易所 | `t187ap05_l/` |
| 集保戶股權分散表 | [11452](https://data.gov.tw/dataset/11452) | 臺灣集中保管結算所 | `tdcc_od_1-5/` |

資料來源：臺灣證券交易所、臺灣集中保管結算所（政府資料開放平臺上表所列資料集）。
此開放資料依政府資料開放授權條款（Open Government Data License）進行公眾釋出，
使用者於遵守本條款各項規定之前提下，得利用之。
政府資料開放授權條款：<https://data.gov.tw/license>

每個檔案的 `meta` 記錄該資料集自己的顯名聲明（`attribution`）、平臺資料集頁面（`dataset_url`）、
實際來源網址（哪一個出口）與取得時間。2026-10-06 以前收的個股行情與指數檔，`attribution` 是兩個資料集合併的聲明。

## 檔案格式

| 路徑 | 內容 | 日期是 |
| --- | --- | --- |
| `stock_day_all/<年>/<日期>.json` | 上市個股日成交資訊（開高低收、成交股數、成交金額、成交筆數） | 交易日 |
| `mi_index/<年>/<日期>.json` | 每日收盤行情：各類指數收盤值（含發行量加權股價指數） | 交易日 |
| `bwibbu_all/<年>/<日期>.json` | 上市個股本益比、殖利率、股價淨值比 | 交易日 |
| `mi_margn/<年>/<日期>.json` | 融資融券餘額（個股） | 交易日（取自下載檔名） |
| `mi_qfiis_cat/<年>/<日期>.json` | 外資及陸資持股比率（依產業類別彙總） | 交易日（取自下載檔名） |
| `mi_qfiis_sort_20/<年>/<日期>.json` | 外資及陸資持股比率前 20 名 | 交易日（取自下載檔名） |
| `t187ap05_l/<年>/<日期>.json` | 上市公司月營收（當月、上月、去年同月與累計，含年增率） | 出表日期（資料月份見每列的「資料年月」） |
| `tdcc_od_1-5/<年>/<日期>.json` | 集保戶股權分散表：每檔依持股分級的人數、股數與比例；只留 4 碼代號（股票與 ETF） | 資料日期（每週） |

每個檔案是 `{"meta": {...}, "rows": [...]}`，`rows` 保留官方的字串值（民國日期、`--` 表示當日無成交），
有 OpenAPI 的資料集欄名一律用 OpenAPI 的名稱（CSV 的欄名只是寫法不同，內容相同）。
價格為當日實際成交價，**未還原權值**。

個股別的全市場外資持股比率不在開放資料之列（證交所只以開放資料釋出類股彙總與持股前 20 名），所以本分支沒有。

## 不在本分支的資料

模型訓練用的歷史價格取自 Yahoo Finance（yfinance），僅供內部研究、不對外提供，因此不放在任何公開分支。
