# 逐年樣本外驗證結果

規則見 `docs/walkforward_prereg.md`；機器可讀的完整結果在 `docs/walkforward_yearly.json`。只有統計量，不含價格、逐檔報酬與逐日分數。

## 閱讀前

- U1 是 2026-09-30 的台灣 50 套到所有年份，有倖存者偏誤，只作對照；判定以 U2（每天當時的成分股）為準。
- 2025 那一折是實驗 #8 的驗證期，V0 的設定參考過它的結果。
- 多空與只做多：分數前、後 20% 等權，每 5 個交易日換股一次（整個測試期一份日曆、不重疊），每次換股的成本＝換掉的比例 × 58.5 bp。
- 同一種作業系統、同版本套件與相同執行緒數下可以逐位元重現；XGBoost 的 subsample 用 C++ 標準函式庫的亂數分布抽列，Windows 與 Linux 抽到的列不同。
- Deflated Sharpe ratio 與 PBO 要等每個變體、每個股票池都有測試結果才算。
